# proj-Alice

## Storyboard

### Cena 1 – O problema
O estudante está utilizando o computador e percebe que seu código não está funcionando. Ele fica preocupado e chama o professor.

**Fala do estudante:**  
"Professor, meu código não compila de jeito nenhum."

### Cena 2 – O professor se aproxima
O professor percebe que o estudante está com dificuldades, vira-se em direção a ele e se aproxima para ajudá-lo.

**Fala do professor:**  
"Hmm, deixe-me dar uma olhada."

### Cena 3 – A aparição do alien
Enquanto o professor se prepara para analisar o código, um alienígena aparece inesperadamente na cena.

**Fala do alien:**  
"Eu sou o Bug-Bug, o gênio do Java."

### Cena 4 – Análise do código
O alien observa o computador e analisa o problema apresentado pelo estudante.

### Cena 5 – Final
O alien explica o erro ao estudante e o professor acompanha a situação, encerrando a animação.
